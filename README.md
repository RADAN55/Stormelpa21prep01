# ELPA21 Prep Stations

Three 30-minute station rotations for the Laurel High School EL block (grades 9–12).

| Station | Coach | Inside |
|---|---|---|
| 1 · ELPA21 Vocabulary | Ms. Alvarez | Direction-word wall, match, question decoder, context clues, word parts, cognate sort, **Word Rush** game |
| 2 · Tasks + Test Tips | Mr. Brooks | Four-domain task tour, Smart or Risky sort, cross-out drill, timed speaking, **Test-Day Showdown** game |
| 3 · Writing Basics | Ms. Patel | Sentence or fragment, Fix it, Stretch it, Order it, guided paragraph, **Error Hunt** game |

Every station has a 30-minute timer, a teacher lesson read aloud with captions and Spanish support, and one-chance autograded questions with a live score.

**Submit:** The *Submit my scores* button sends name, class period, station scores, exit writing and game scores straight to the teacher's Jotform. A backup link opens the same form with the work already filled in.

**Agenda board:** `agenda.html` is the projector board, with the essential question, objectives, an editable group rotation chart, a 30-minute round timer with chime, and step checklists for each station.

Open one station directly: add `#station-1`, `#station-2` or `#station-3` to the address.
